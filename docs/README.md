# CineBook — Project Documentation

This directory contains the requirements, design documents, and architectural decisions for CineBook.

## Documentation Structure

- `requirements/` — Product requirements and business rules
- `design/` — Database design, API contracts, and system architecture
- `decisions/` — Architecture Decision Records (ADRs)

## Development Process

Requirement → Design → Implementation → Testing → Deployment

Documents will be created and updated incrementally as features are developed.
